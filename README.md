# OpenClaw Study

Kho note học tập của Đại ca, được chia theo từng mảng để học dần và mở rộng lâu dài.

## Chủ đề
- `system-design/` — kiến trúc hệ thống, trade-off, pattern, interview notes
- `dsa/` — cấu trúc dữ liệu và giải thuật
- `ai/` — AI, machine learning, LLM, ứng dụng thực tế
- `devops/` — Linux, cloud, CI/CD, containers, IaC, Kubernetes, vận hành hệ thống

## Gợi ý dùng repo
- Mỗi topic là một file `.md`
- Khi học xong một buổi, cập nhật note ngắn: khái niệm, ví dụ, trade-off, lỗi hay gặp
- Ưu tiên viết theo kiểu dễ ôn lại, không nhồi lý thuyết vô nghĩa
