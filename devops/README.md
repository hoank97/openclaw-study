- Linux fundamentals
- Networking for DevOps
- Bash / Python automation
- Nginx / reverse proxy
- Docker / Docker Compose
- GitHub Actions / GitLab CI
- AWS basics
- Terraform
- Kubernetes
- Prometheus / Grafana / logging
- DevSecOps basics
