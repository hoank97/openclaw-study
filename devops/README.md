- `roadmap-devops.md` — lộ trình học DevOps tổng thể
- `linux-commands.md` — các lệnh Linux căn bản cho DevOps
- `linux-permissions-process-logs.md` — quyền file, process, service, logs
- `bash-scripting-basics.md` — Bash scripting cơ bản cho DevOps
